Quota order — lượt xác nhận đơn (mô hình thuê A)Order quota — confirmed orders (Model A)

Phí duy trì tính theo chi nhánh / tháng, mỗi gói bao gồm số lượt order phù hợp quy mô bàn. Tất cả chi nhánh vận hành trên cùng nền tảng Linm.Monthly fee is per branch; each tier includes confirmed-order units matched to table count. All branches run on the shared Linm platform.

1 lượt quota = khách order trên QR bàn và quán xác nhận đơn (NV xác nhận → gửi bếp). Một lần xác nhận — dù đơn có nhiều món — không tính từng món; không tính riêng bước thanh toán hay đóng bàn. Tham chiếu quy mô ghi lượt/bàn/ngày (trung bình mỗi bàn mỗi ngày); quota hóa đơn tính tổng lượt/CN/tháng. 1 quota unit = guest places an order via table QR and the venue confirms the order (staff confirm → kitchen). One confirmation per submission — not per line item; not a separate payment or table-close step. Size reference uses units/table/day (average per table per day); billing quota is total units/branch/month.
